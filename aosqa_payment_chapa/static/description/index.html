Chapa Payment Integration

This module integrates Chapa Payment Gateway with Odoo, enabling secure and seamless online payments for your business.

Key Features

  • Accept payments via Chapa
  • Secure transaction processing
  • Supports multiple payment methods
  • Automatic payment confirmation
  • Easy configuration in Odoo

Supported Odoo Apps

  • eCommerce
  • Invoicing
  • Sales

Configuration

  1. Install the module
  2. Go to Payment Providers
  3. Add Chapa credentials (Public Key & Secret Key)
  4. Enable the provider

Requirements

  • Odoo 17
  • Active Chapa account
